## 3. Quiz Application

### Description
This is a console-based quiz application that asks multiple-choice questions
and displays the final score at the end of the quiz.

### Features
- Questions loaded from a JSON file
- Random shuffling of questions and options
- Score calculation and display
- User-friendly console interaction

### Concepts Used
- JSON file handling
- Lists and Dictionaries
- Loops and Conditional Statements
- Random module
